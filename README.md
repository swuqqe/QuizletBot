# 📖 QuizletBot — тренажер українських фразеологізмів

Telegram-бот для вивчення українських фразеологізмів у форматі флеш-карток,
на кшталт Quizlet, з повноцінною системою навігації: головне меню, статистика
за весь час, налаштування мови (UA/EN) та розділ "Про бота".

## 🗺 Структура меню

```
🏠 Головне меню
├── 🎴 Картки        → вибір кількості (5/15/25/50) → сесія карток → підсумок
├── 📊 Статистика    → загальна кількість переглянутих карток за весь час
├── ⚙️ Налаштування  → перемикач мови UA / EN
└── ℹ️ Про бота       → технології, контакт розробника
```

Кожен екран має кнопку **🏠 Головне меню** (а статичні підменю — ще й
**◀️ Назад**), тож "зайти в глухий кут" неможливо — з будь-якого місця можна
повернутись.

## ✨ Як це виглядає

1. `/start` → головне меню з 4 розділами
2. **🎴 Картки** → обираєте кількість карток (5, 15, 25 або 50)
3. Бот показує фразеологізм → тап **🔄 Показати пояснення** → картка "перевертається"
4. Позначаєте **⬅️ Не знаю** / **➡️ Знаю** → бот одразу видає наступну картку
5. Коли ліміт карток вичерпано — підсумковий екран: скільки переглянуто,
   скільки "знаю"/"не знаю", кнопки **🔄 Спробувати ще раз** (та сама кількість)
   і **🏠 Головне меню**

> Свайпи як жест Telegram-боти технічно не підтримують — тому "свайп ліво/право"
> реалізований як тап по кнопці. Функціонально це те саме.

## 🗂 У базі

**244 українських фразеологізми** з поясненнями значень — від класичних
("бити байдики", "водити за ніс") до менш очевидних.

## 🛠 Технології

- [.NET 8](https://dotnet.microsoft.com/) / C#
- [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot) — офіційна .NET-обгортка для Telegram Bot API
- Long polling (без вебхуків — не потрібен публічний сервер із HTTPS)
- Проста файлова персистентність (`userdata.json`) для статистики й мови — без зовнішньої БД

## 🚀 Запуск

### Що потрібно

- [.NET 8 SDK](https://dotnet.microsoft.com/download) (або новіший)
- Токен бота від [@BotFather](https://t.me/BotFather)

### Кроки

```bash
git clone https://github.com/ваш-нік/QuizletBot.git
cd QuizletBot

# Скопіюйте приклад конфігурації й впишіть свій токен
cp appsettings.example.json appsettings.json
# Відкрийте appsettings.json і замініть YOUR_BOT_TOKEN_HERE на свій токен

dotnet restore
dotnet run
```

Або передайте токен через змінну середовища замість файлу:

```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_тут"
dotnet run
```

Після запуску в консолі з'явиться:
```
✅ Бот @your_bot_username запущено. Картотека: 244 фразеологізми.
```

Відкрийте бота в Telegram і надішліть `/start`.

## 💬 Команди бота

| Команда   | Дія                              |
|-----------|-----------------------------------|
| `/start`  | Привітання + головне меню          |
| `/menu`   | Показати головне меню в будь-який момент |

Решта навігації — повністю через inline-кнопки під повідомленнями.

## 📁 Структура проєкту

```
QuizletBot/
├── Program.cs                      # bootstrap: конфіг, запуск бота
├── Handlers/
│   └── UpdateHandler.cs            # маршрутизація всіх колбеків і команд
├── Models/
│   ├── Phraseologism.cs            # модель картки
│   ├── UserSession.cs              # тимчасовий стан сесії (стан навігації, лічильники)
│   ├── UserData.cs                 # персистентні дані (мова, статистика за весь час)
│   └── Language.cs                 # enum UA/EN
├── Services/
│   ├── PhraseologismRepository.cs  # завантаження й вибір випадкової картки без повторів у сесії
│   ├── SessionManager.cs           # сесії користувачів у пам'яті
│   ├── UserDataStore.cs            # файлова персистентність (userdata.json)
│   └── UiRenderer.cs               # текст + клавіатура для кожного екрана
├── Resources/
│   └── Strings.cs                  # усі тексти інтерфейсу UA/EN в одному місці
├── Data/
│   └── phraseologisms.json         # база фразеологізмів (244 записи)
├── appsettings.example.json        # приклад конфігурації (без токена)
└── appsettings.json                # ваш реальний токен (у .gitignore, не в репо)
```

## 🧭 Як влаштована навігація (для розробників)

Callback data всюди має формат `namespace:action[:param]`:

| Приклад               | Означає                                    |
|------------------------|---------------------------------------------|
| `nav:main`             | Показати головне меню                       |
| `nav:flashcards`       | Показати вибір кількості карток             |
| `nav:stats` / `nav:settings` / `nav:about` | Відповідне статичне підменю   |
| `fc:count:15`          | Почати сесію з 15 карток                    |
| `fc:flip:42`           | Перевернути картку id=42                    |
| `fc:know:42` / `fc:dontknow:42` | Позначити картку й показати наступну |
| `settings:lang:EN`     | Перемкнути мову на англійську               |

Стан користувача (`SessionState`: Idle / ChoosingCount / Active / Ended)
зберігається в `UserSession` і використовується, щоб ігнорувати застарілі
колбеки (наприклад, натискання на кнопку картки з уже завершеної сесії) —
без падінь і "осиротілих" екранів.

## ➕ Додати свої фразеологізми

Відкрийте `Data/phraseologisms.json` і додайте новий об'єкт у масив:

```json
{
  "text": "Ваш фразеологізм",
  "explanation": "Його пояснення"
}
```

Поле `id` можна не вказувати — проставиться автоматично.

## 🔒 Безпека токена

Файл `appsettings.json` з реальним токеном навмисно виключений через
`.gitignore` і не потрапляє в репозиторій. Якщо клонуєте цей репозиторій —
створіть свій `appsettings.json` за прикладом `appsettings.example.json`
або скористайтесь змінною середовища `TELEGRAM_BOT_TOKEN`.
